# Changelog

## peeky 0.1.0

- `peeky` is a package that allows users to peek at the source code of a
  Shinylive application.
  - It works with both standalone and embedded Shinylive applications
    written using either R or Python.
- The package provides the following functions:
  - [`peek_shinylive_app()`](https://r-pkg.thecoatlessprofessor.com/peeky/reference/peek_shinylive_app.md)
    is the primary function for examining Shinylive applications.
  - [`peek_standalone_shinylive_app()`](https://r-pkg.thecoatlessprofessor.com/peeky/reference/peek_standalone_shinylive_app.md)
    is the primary function for examining standalone Shinylive
    applications.
  - [`peek_quarto_shinylive_app()`](https://r-pkg.thecoatlessprofessor.com/peeky/reference/peek_quarto_shinylive_app.md)
    is the primary function for examining Quarto documents with embedded
    Shinylive applications.
